How to use

Gestures

  • One-finger drag — move the Mac cursor
  • Tap — left click
  • Two-finger tap — right click
  • Two-finger drag — scroll
  • Pinch — zoom in / out (⌘ + scroll)
  • Press & hold, then move — select / drag

Gyro mode

  • Point the phone like a remote — the Mac cursor follows where you aim
  • Recenter aim maps your current phone direction to the screen center
  • Range controls how far you need to tilt to reach the screen edges
  • iPhone: open the https:// URL from the server (sensors need a secure page)

Fullscreen

  • iPhone: Share → Add to Home Screen, then open the icon
  • Android: browser menu → Install app / Add to Home screen

Connection

Green — connected and ready
Amber — connecting or reconnecting
Red — disconnected
